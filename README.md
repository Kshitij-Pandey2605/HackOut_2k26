# HackOut 2k26 — CarbonSphere Frontend

> **AI-Powered Circular Carbon Exchange Ecosystem**

Welcome to the **CarbonSphere** frontend repository for HackOut 2k26.

## 🚀 Quick Start

```bash
# Navigate to the frontend directory
cd carbonsphere-frontend

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

Visit `http://localhost:3000` to launch the CarbonSphere Command Center.
